## ⚙️ Local Setup

### Prerequisites

- **Node.js v18+** → [nodejs.org](https://nodejs.org)
- **MongoDB** (local or [Atlas cloud](https://mongodb.com/atlas))

### Quick Start

```bash
# 1. Clone
git clone https://github.com/yashika-34/Assignment-Plagarism.git
cd Assignment-Plagarism

# 2. Install
npm install

# 3. Configure
copy .env.example .env
```

Edit `.env`:
```env
PORT=3000
MONGODB_URI=mongodb://127.0.0.1:27017/assigncheck
JWT_SECRET=your_long_random_secret_here_min_32_chars
```

```bash
# 4. Run
npm start
```

🌐 Open **[http://localhost:3000](http://localhost:3000)**

## 🔐 Security

<details>
<summary><b>🛡️ Security model</b></summary>

| Feature | Implementation |
|---|---|
| Password storage | bcrypt hashed (10 rounds), never plain text |
| Authentication | JWT Bearer tokens (7-day expiry) |
| Password reset | 6-digit time-limited OTP (15 min) |
| Student isolation | Students access **only their own** reports |
| Teacher access | Full report + user data visibility |
| Score integrity | Server **recalculates** from raw text — ignores client scores |
| XSS prevention | File names via `.textContent`, never `innerHTML` |
| Rate limiting | 30 auth / 15 min • 500 general / 15 min |

</details>

## 📐 Algorithm

<details>
<summary><b>🔬 Symmetric Jaccard Similarity explained</b></summary>

AssignCheck splits each document into **4-word sliding shingles**, then computes:

```
Similarity(A, B) = |shingles(A) ∩ shingles(B)|  ×  100%
                   ─────────────────────────────
                   |shingles(A) ∪ shingles(B)|
```

**Guaranteed symmetric**: `Sim(A, B)` always equals `Sim(B, A)`.

### Typo-Tolerant Matching
Words with Levenshtein distance ≤ 1 (short) or ≤ 2 (long) are fuzzy-aligned before shingling — spelling mistakes still count toward similarity.

### Directional Coverage
```
A→B coverage = |A ∩ B| / |A|  ×  100%   (how much of A is in B)
B→A coverage = |A ∩ B| / |B|  ×  100%   (how much of B is in A)
```

### Performance (Batch Mode)
- Student-vs-teacher: **parallel batches of 3** (no waiting)
- Peer collusion matrix: **instant local Jaccard** (zero API calls)

</details>

## 🚀 Deploy on Render

```yaml
# render.yaml is already included — just connect your repo!
```

1. Fork this repo
2. [dashboard.render.com](https://dashboard.render.com) → **New Web Service**
3. Connect `yashika-34/Assignment-Plagarism`
4. Add environment variables:

| Key | Value |
|---|---|
| `MONGODB_URI` | Your MongoDB Atlas URI |
| `JWT_SECRET` | A long random string |

5. Click **Deploy** ✅ — auto-deploys on every push to `main`
